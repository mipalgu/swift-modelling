# Change Detection and Reconciliation

## Comparing Models, Not Files

A textual `diff` of `project-data.xmi` and `updated-project-data.json`
is useless: the formats differ in every line. Instead, compare the models:

```
swift-ecore compare project-data.xmi updated-project-data.json -m ProjectManagement.ecore
```

The comparison loads both files with the metamodel, so the format does not
matter. Objects are matched by class and identifier (the `id` attribute
that the metamodel marks as `iD`), and the differences are reported per
object and feature:

| Line | Meaning                                                    |
|------|------------------------------------------------------------|
| `+`  | an object exists only in the revised model                 |
| `-`  | an object exists only in the original model                |
| `~`  | an attribute or reference of a matched object has changed  |

An attribute that a file leaves unset reads as its default value, so a
first value for `actualHours` appears as a change from `0.0`.
`--summary` counts the objects of each class in both versions instead.

`--exit-code` makes the command fail when there are differences, which
turns it into a check for scripts.

## Domain Rule for Reconciliation

Edits from different tools can each be valid against the metamodel and
still break a rule of the domain. The web editor marked MS-002 complete
although its deliverable TASK-004 is still in progress.

Rule: **a milestone is complete exactly when all of its deliverables are
COMPLETED.** The milestone flag is derived from the tasks, so the tasks win.

`ReconcileProject.atl` applies this rule as a refining transformation:
it rewrites only the milestones that break the rule and copies everything
else unchanged. Comparing the model before and after the transformation
shows exactly what the rule changed.

## Round-Trip Fidelity

Before the desktop tool receives JSON-edited data, check that converting
XMI to JSON and back loses nothing:

```
swift-ecore convert project-data.xmi sync/roundtrip.json -m ProjectManagement.ecore
swift-ecore convert sync/roundtrip.json sync/roundtrip.xmi -m ProjectManagement.ecore
swift-ecore compare project-data.xmi sync/roundtrip.xmi -m ProjectManagement.ecore --exit-code
```
